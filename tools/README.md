# tools/ 工具索引

## 使用规则

- 启动时只读本索引；调用某个工具前，先读该工具自己的 README。
- 命令一律从工作空间根目录执行。
- 凭据只载入环境变量，不打印、不写进任何输出。本索引只写凭据文件名，不写内容。
- 会对外写数据的工具（上传、发送、发布），必须等我明确确认，并且带上该工具的确认参数。
- 新增工具：建 `tools/<工具名>/README.md`，再在下表加一行。
