# skills/ 技能索引

## 加载规则

- 启动时只读本索引，不读各个 SKILL.md。
- 任务匹配到某个技能时，再读该技能的 SKILL.md 全文后执行；不凭记忆执行，不读无关技能。
- 技能只放本目录，不放进任何工具专属的技能目录（`.claude/skills/`、`.agents/skills/` 等），这样每个智能体都能用。
- 新增技能：建 `skills/<技能名>/SKILL.md`，再在下表加一行。`tools/check-workspace/check.py` 会核对目录和索引是否一一对应。
- 技能目录里如果有 `.env`，只载入环境变量，不打印、不复制到别处。
