# save-memory：记忆草稿与确认写入

规则以 `AGENTS.md` 第 5 节为准，本技能只是执行步骤。

## 1. 找出可记的条目

从本次对话里只挑这三类：

- 我明确拍板的决定。
- 我提供的数据，以及我认可的结论。
- 我否决的方案（写进「已推翻」，防止以后绕回去）。

不记：智能体自己的建议和推测、过程记录、版本流水、规则文件里已经写了的内容。

## 2. 出草稿

每条一行，格式：

```text
[建议写入] memory/MEMORY.md ·「<节名>」
- <一句话结论>（YYYY-MM-DD）
```

- 替代旧结论时，同时列出要改的原行，以及要移进「已推翻」的那一行：`旧结论 → 新结论（日期）`。
- 草稿里不出现密码、Token、API Key、内部地址、他人的个人信息。
- 没有可记内容，就直接说「本次无需记录」。

## 3. 等确认

- 我可以逐条确认、修改或删掉。
- 只有收到「写」「存」「确认」这类明确的肯定回复才落盘；含糊的回复（「嗯」「再说」）不算。

## 4. 落盘

- 写入对应的节，按主题放，不往文件末尾追加。
- 写完检查文件不超过 200 行；接近上限时出一版精简草稿，等我确认。
- 回报：写进了哪个文件哪一节、写了几条。
