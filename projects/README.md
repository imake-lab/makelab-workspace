# projects/ 项目

每个项目一个目录，目录里的 `README.md` 写这个项目自己的约定：做什么、给谁、资料在哪、成品放哪、有哪些特殊要求。

- 这是第二层加载：我说明本次做哪个项目后，智能体才读对应的 README（见 `AGENTS.md` 第 2 节）。
- 项目目录里**不放** `AGENTS.md` / `CLAUDE.md`。项目约定写在 `README.md` 里，由根规则指过来读，避免出现第二套规则。
- 项目约定和根规则冲突时，以根规则的权限与安全条款为准，并报告给我。
