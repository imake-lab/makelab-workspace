# example — 每周汇总团队周报（示例项目）

> 示例，用来演示项目约定怎么写。换成你自己的项目后删掉本目录，并更新 `projects/README.md`。

## 做什么

- 每周五汇总团队成员的周报，交给上级一份总览。

## 读者

- 我的上级。看完要知道整体进度和风险。

## 资料

- 每次的输入放在 `projects/example/资料/`，同一份资料只留最新版。
- 没有我点名的文件不要用。

## 成品

- 放到 `outputs/周报汇总-YYYY-MM-DD/`。
- 格式：先写结论，再按项目写进度，最后单列风险。
- 缺的信息单列「待补」，不硬填。

## 流程

1. 先列提纲给我确认。
2. 确认后写全文。
3. 原始资料只读不改。
